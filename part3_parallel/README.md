# Часть 3. Многопоточная и многопроцессорная обработка данных

Программа для параллельной аугментации изображений с использованием паттерна **«Производитель-Потребитель»**.

## Архитектура

*   **Поток-производитель**: сканирует директорию и помещает пути к файлам в `queue.Queue`.
*   **Потоки-потребители**: читают пути, загружают изображения через `PIL` и передают массивы NumPy в следующую очередь.
*   **Пул процессов (`multiprocessing.Pool`)**: забирает массивы и применяет аугментацию (повороты, отражения, шум).

Для синхронизации используются `threading.Lock` (защита счетчика) и очереди. Результаты сравнения времени последовательной и параллельной версий сохраняются в `performance_report.json`.

## Установка и запуск

1. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Поместите тестовые изображения** (`.jpg`, `.png`) в папку `data/input`.

3. **Запустите программу** из корневой папки `part3_parallel`:
   ```bash
   python main.py
   ```

4. **Проверьте результаты**: после завершения откройте файл `performance_report.json`, чтобы увидеть время последовательной и параллельной обработки и коэффициент ускорения.

**Важно:** Для корректной работы `multiprocessing` на Windows запуск должен производиться из блока `if __name__ == "__main__":` (уже реализовано в `main.py`).

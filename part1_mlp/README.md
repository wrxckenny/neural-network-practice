# Часть 1. Объектно-ориентированная реализация многослойного перцептрона

Данный проект представляет собой реализацию полносвязной нейронной сети (многослойного перцептрона) с одним скрытым слоем на языке Python с использованием библиотеки NumPy. Проект написан в парадигме ООП и включает консольное меню для взаимодействия с пользователем.

## Функциональные возможности

*   **Класс `NeuralNetwork`**: 
    *   Инициализация весов случайными малыми числами.
    *   Прямой проход (Forward pass) с поддержкой функций активации `sigmoid` и `relu`.
    *   Обратный проход (Backpropagation) с использованием градиентного спуска.
    *   Обучение на мини-батчах с сохранением истории ошибок (MSE).
    *   Сохранение и загрузка весов в формате JSON.
*   **Класс `DatasetManager`**:
    *   Загрузка данных из CSV-файла (последний столбец — целевая переменная).
    *   Нормализация признаков методом Min-Max.
    *   Разбиение выборки на обучающую и тестовую (Train/Test).
*   **Обработка ошибок**: Реализованы собственные классы исключений (`InvalidLayerSizeError`, `MismatchedDataError` и др.).
*   **Визуализация**: Построение графика изменения функции потерь с помощью `matplotlib`.

## Установка и запуск

1. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Запустите программу** из корневой папки проекта (`part1_mlp`):
   ```bash
   python -m app.main
   ```

## Формат входных данных (CSV)

Программа ожидает CSV-файл, в котором:
*   Первая строка — заголовки столбцов.
*   Все столбцы, кроме последнего — признаки (features).
*   Последний столбец — целевая переменная (target).

Пример (`data.csv`):
```csv
feature1,feature2,target
0.1,0.2,0
0.4,0.5,0
0.7,0.8,1
0.9,0.9,1
0.2,0.8,0
0.8,0.2,1
0.3,0.3,0
0.6,0.7,1
0.1,0.9,0
0.9,0.1,1
```

## Пример использования

1. Выберите пункт `1` для создания сети (например, 2 входа, 4 скрытых нейрона, 1 выход, активация `sigmoid`).
2. Выберите пункт `2` и укажите путь к файлу `data.csv`.
3. Выберите пункт `3` для обучения (например, learning rate = 0.1, epochs = 500, batch size = 2).
4. Проверьте работу сети через пункт `4` (предсказание).
5. Постройте график ошибки через пункт `7`.

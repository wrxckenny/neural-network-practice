# Практические задания по дисциплине «Основы нейронных сетей»

Данный репозиторий содержит решения трех практических заданий, демонстрирующих навыки разработки на Python в контексте машинного обучения и нейросетей.

## Структура проекта

*   **`part1_mlp/`** — Объектно-ориентированная реализация многослойного перцептрона (MLP) с нуля на NumPy. Включает прямое/обратное распространение, градиентный спуск и консольное меню. (Подробнее в `part1_mlp/README.md`)
*   **`part2_prepare/`** — CLI-утилита для сканирования директорий, подготовки данных (изображения/CSV), нормализации и сохранения в `.npy`. Включает команду `doctor` для проверки окружения. (Подробнее в `part2_prepare/README.md`)
*   **`part3_parallel/`** — Многопоточная и многопроцессорная обработка данных (аугментация изображений) с использованием паттерна Producer-Consumer и замером производительности. (Подробнее в `part3_parallel/README.md`)

## Требования к окружению

*   Python 3.8+
*   Зависимости указаны в `requirements.txt` внутри каждой папки.

## Общая инструкция по запуску

1. Создайте виртуальное окружение:
   ```bash
   python -m venv venv
   ```
2. Активируйте его:
   *   Windows: `venv\Scripts\activate`
   *   Linux/macOS: `source venv/bin/activate`
3. Установите зависимости для нужной части:
   ```bash
   pip install -r part1_mlp/requirements.txt
   ```
4. Перейдите в папку нужной части и следуйте инструкциям в её локальном `README.md`.

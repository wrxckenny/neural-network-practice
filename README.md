# Практические задания по дисциплине «Основы нейронных сетей»

Данный репозиторий содержит решения трех практических заданий, демонстрирующих навыки разработки на Python в контексте машинного обучения.

## Структура проекта

*   **`part1_mlp/`** — Объектно-ориентированная реализация многослойного перцептрона (MLP) с нуля на NumPy. Включает прямое/обратное распространение, градиентный спуск и консольное меню.
*   **`part2_prepare/`** — CLI-утилита для сканирования директорий, подготовки данных (изображения/CSV), нормализации и сохранения в `.npy`. Включает команду `doctor` для проверки окружения.
*   **`part3_parallel/`** — Многопоточная и многопроцессорная обработка данных (аугментация изображений) с использованием паттерна Producer-Consumer и замером производительности.

## Требования к окружению

*   Python 3.8+
*   Зависимости указаны в `requirements.txt` внутри каждой папки.

## Установка и запуск

Для каждой части предусмотрена отдельная инструкция в её `README.md`. Общий порядок:
1. Создайте виртуальное окружение: `python -m venv venv`
2. Активируйте его (Windows: `venv\Scripts\activate`, Linux/Mac: `source venv/bin/activate`)
3. Установите зависимости: `pip install -r part1_mlp/requirements.txt` (и так далее для остальных частей).

# Часть 2. CLI-утилита для подготовки данных и проверки окружения

Консольное приложение на Python для автоматизации подготовки данных (изображения/CSV) и диагностики рабочего окружения.

## Команды

### 1. `prepare`
Рекурсивно обходит директорию, читает файлы указанных расширений, нормализует их (деление на 255 для изображений) и сохраняет в единый `.npy` файл. Также выводит статистику обработки.

**Аргументы:**
*   `--path` — путь к папке с данными.
*   `--ext` — расширения файлов через запятую (например, `jpg,png`).
*   `--output` — имя выходного `.npy` файла.

**Пример:**
```bash
python -m app.cli prepare --path data/input --ext jpg,png --output dataset.npy
```

### 2. `doctor`
Проверяет окружение: версию Python, наличие библиотек (NumPy, Pillow, TensorFlow/PyTorch), доступность CUDA (через `nvidia-smi`) и текущую рабочую директорию.

**Пример:**
```bash
python -m app.cli doctor
```

## Конфигурация
Настройки (пути, уровень логирования) читаются из переменных окружения (`.env`), CLI-аргументов или значений по умолчанию. Пример переменных находится в файле `.env.example`.

## Установка и запуск

1. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Запустите нужную команду** из корневой папки `part2_prepare`:
   ```bash
   python -m app.cli doctor
   ```
